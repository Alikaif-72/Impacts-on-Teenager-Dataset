📱 Social Media Impact on Teenagers

Data Analysis & Behavioral Analytics Project Report


Prepared By : Alikaif jafri

📌 Introduction

Social media has become an important part of teenagers' daily lives. Excessive use of social media platforms may affect mental health, sleep quality, academic performance, and overall lifestyle behavior. This project focuses on analyzing teenagers' behavioral patterns using data analysis techniques and feature engineering.

🎯 Objectives

  • Analyze teenagers’ social media usage behavior
  • Study the relationship between screen time and mental health
  • Understand the effect of sleep and physical activity
  • Perform feature engineering for better analysis
  • Prepare the dataset for machine learning models

📂 Dataset Description

Column Name Description
daily_social_media_hours Daily social media usage hours
platform_usage Most used social media platform
screen_time_before_sleep Screen usage before sleeping
sleep_hours Average sleeping hours
stress_level Stress score
anxiety_level Anxiety score
addiction_level Social media addiction level
academic_performance Academic performance score
depression_label Depression prediction label

🧹 Data Cleaning & Preprocessing

  • Removed duplicate values
  • Handled missing values
  • Validated logical ranges
  • Handled outliers using IQR method
  • Standardized categorical values
  • Reorganized dataset columns

⚙ Feature Engineering

mental_health_score

Combined indicator created using stress, anxiety, and addiction levels.

sleep_category

Categorized sleep quality into Poor, Average, and Good.

usage_category

Categorized social media usage into Low, Moderate, and High.

wellness_score

Combined score of sleep, physical activity, and academic performance.

🔍 Key Insights

  • Higher social media usage may increase stress and anxiety
  • Late-night screen exposure may reduce sleep quality
  • High addiction levels may negatively affect academics
  • Physical activity may improve wellness and mental health

This project demonstrates how social media usage patterns influence teenagers' mental health, sleep quality, academic performance, and overall lifestyle behavior. The dataset provides strong opportunities for data analysis, behavioral analytics, and machine learning applications.
